# Keystock — preview

A working preview of a one-page-website studio's own site, published so it can be
opened on a real phone. It is **not** a live business site.

- The six businesses on the device wheel are **invented demonstrations**, not
  clients. Their phone numbers are in ACMA's range reserved for fiction.
- The enquiry form **is not connected**. Nothing typed into it is sent or stored.
- The page carries `noindex, nofollow`, for both of the reasons above.

This repository holds only the built page. The source, and everything else, is
private.
